# 地理围栏体系 · Geofence & Geo-Econ System

**深圳数据经济研究院 · 卫星遥感数据研究中心**

**在线地图**：https://cangmingguoke.github.io/geofence-geoecon-system/

连接卫星遥感与行政区经济金融数据的**空间桥梁**：把没有行政边界的遥感观测（夜间灯光、土地利用、企业点位等）与按行政区汇报的经济金融数据（GDP、企业注册、人口等）对齐到同一套空间编码，支撑"天—地"数据融合与下游分析。

## 项目背景与用途

卫星遥感观测以经纬度 / 像元为载体，经济金融数据以行政区划为口径，两者天然"天—地"分离。本体系解决三类问题：

- **点 → 行政区空间匹配**：任意经纬度（遥感像元、POI、企业点位）可落到国家 / 省 / 市 / 区县四层，返回统一 GID 编码。
- **遥感指标行政聚合**：把栅格遥感观测按行政边界聚合为省 / 市 / 区县级指标，作为经济活动与城市化的空间代理变量。
- **跨尺度口径统一**：以同一套四层 GID 编码对齐多来源、多分辨率数据，支撑面板回归、空间计量等下游分析。

## 一、GADM 交互地图

覆盖近五年名义 GDP 前 20 国的**国家 / 省 / 市 / 区县**四级行政区划，自研 Canvas 矢量渲染器（非 Leaflet），支持大洲/国家切换、L1–L4 层级缩放、城市中英文标注切换、滚轮缩放/拖拽平移、悬停显示、搜索高亮（中文/拼音，按唯一 GID 定位避免同音歧义）。

数据源与构建流程、字段字典、覆盖范围、中国数据处理细节（台湾省级并入、区县 GB/T 2260 审计修复等）详见 `GADM/README.md`。

## 二、经济定义研究管线（美国样例）

以 OE「全球城市」经济定义（Global_Cities_Definitions_Oct19）为真值，把**经济意义上的都市圈**（Metropolitan Statistical Area，跨州、跨县）与 GADM 行政边界对齐，产出可在地图上叠加的经济图层。九步流程：

| 阶段 | 内容 | 关键产物 |
|---|---|---|
| 底座盘点 | 梳理产品底座 | `00_产品底座盘点.md` |
| 底表构建 | 经济定义成员表 + GADM 州/县底表 | `01_*` `02_*` `03_*` |
| 成员匹配 | FIPS↔GADM 县代码桥 + 563 成员匹配 | `04_FIPS_GADM县代码桥.csv`、`04_匹配结果_全量563.csv` |
| 单圈验证 | 单都市圈围栏（Atlanta / New York） | `05_USM01_*` `05_USM13_*` |
| 批量生成 | 88 都市圈围栏 + 质量检查 | `07_美国都市圈边界.geojson/.gpkg`、`07_质量检查报告.md` |
| 审核版本化 | 人工审核 + 版本记录（命令行最小闭环） | `08_审核工具.py`、`08_审核日志/状态/版本记录.csv` |
| 图层集成 | 经济图层挂进产品地图 | `09_生成经济图层.py`、`GADM/map_data/USA_metro.js` |

美国样例规模：**88 个都市圈（MSA）、563 条县级成员记录、覆盖 44 州**。匹配 561/563，2 处缺失（Baltimore City、St. Louis City 在 GADM 中无对应县，按决议"标注缺失留缺口"处理）。

审核与版本化采用**机器结果 + 追加式审计日志 + 幂等重算**的最小数据闭环，原始匹配结果只读、永不被覆盖。
