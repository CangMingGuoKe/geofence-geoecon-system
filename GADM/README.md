# 全球地理围栏四层体系 · 交互地图

深圳数据经济研究院 · 卫星遥感数据研究中心

**在线地图**：https://cangmingguoke.github.io/geofence-geoecon-system/

## 简介与用途

一套国家 / 省州 / 市郡 / 区县四级行政区划围栏，覆盖 31 国。用途是把遥感像元、企业点位等没有行政边界的观测落到统一 GID，或把栅格指标按行政区聚合，支撑面板回归与空间计量。公开仓库只放交互地图与简化几何，原始边界与构建脚本在院内本地。

- 四级缩放，大洲与国家切换，中英文标注
- 中文、拼音检索，按 GID 定位，同名项带上级标签
- `match_points` 批量点匹配，GeoJSON 与 GeoPackage 双格式

## 字段字典

| 层级 | 名称 | GADM 层级 |
|---|---|---|
| L1 | 国家 | ADM0 |
| L2 | 省州 | ADM1 |
| L3 | 市郡 | ADM2 |
| L4 | 区县 | ADM3 |

> 德国、西班牙的 L4 不用 GADM ADM3。德国是 4,680 个市镇与联合体混杂的单元，西班牙是 369 个 Comarca 且 79% 名字为 n.a.。两国改用 Eurostat GISCO 的 LAU 2024，德国 10,978 个、西班牙 8,132 个市镇，边界署名 © EuroGeographics。整理脚本 `scripts/prepare_lau.py`，加载逻辑见 `scripts/build_interactive_map.py` 的 `extract_lau()`。

> 城市分区叠加层 3,484 条：德国 8 城 95 个区，西班牙 1,066 个多区市镇 3,389 个 distrito。取自各市官方数据与 INE 2025 年普查区。独立叠加层，不并入四层、不进检索索引。构建脚本 `scripts/build_city_districts.py`、`scripts/build_spain_districts.py`，来源写在每条记录的 `src` 字段。

每个要素保留 GADM 原始字段，另写五个：

- `GID_N`：第 N 级唯一编码，如 `FRA.1.1_1`，空间主键
- `NAME_N` / `NL_NAME_N`：英文名 / 本地名
- `TYPE_N` / `ENGTYPE_N`：本地 / 英文行政类型
- `level` / `admin_level`：本体系 1 至 4 级 / GADM 0 至 3 级
- `geometry`：Polygon 或 MultiPolygon，统一 WGS84

更深的层级（如法国公社 ADM4）已按四层规范舍弃，不足四层的国家不产出该层文件。

**名字不能当键。** 美国 L3 共 3,148 个县，442 个名字重复，Washington 有 31 个；HASC 由名称推导，8 组撞码；另有 11 个五大湖水体要素，真县为 3,137 个。匹配、去重与关联一律用 GID。

## 构建流程

1. 从 GADM 4.1 下载各国各层原始数据，留在本地 `raw/`。
2. 统一到 WGS84，写入 `level` 与 `admin_level`。
3. 按国家与层级输出 GeoJSON，每国一个 GeoPackage。
4. 中国层换源 CTAmap，见下节。
5. 生成交互地图与检索索引，部署到 GitHub Pages。

`map_data/*.js` 是简化几何（`SIMPLIFY = 0.002` 度，约 220 米），只用于展示与点选，不能算面积；精确边界以 `gpkg/` 为准。

## 中国数据

中国四层已由 GADM 换源至 CTAmap（省市县数据库，断面 2023-12-31），县级要素由 2,420 增至 2,858，并补上藏南、南海诸岛（含三沙市）。台湾作为省级单元并入，中印争议区保留并归属新疆、西藏，澳门 8 个堂区统一标注。十段线另作线层。

GADM 时期的区县层做过一轮审计与修复，修正 444 处，但仍有三类问题：民政部 2,844 个县级单元里 894 个在 GADM 无对应几何、2,420 个县级要素里 408 个名字对不上、32 处错挂父级。这是换源的直接原因。**涉华地图不可作正式出版图**，精确边界请用自然资源部标准地图或民政部数据。

换源后的口径、新旧差异与 2024 至 2026 年区划变更，见 [`docs/中国围栏换源说明.md`](../docs/中国围栏换源说明.md)。

## 已知缺陷

### 美国层

GADM 对「县与独立市同名」处理不一致。弗吉尼亚的 Fairfax、Roanoke、Bedford 三对县市各自成块，但共用同一个 HASC 码；巴尔的摩市与圣路易斯市则被并进同名县：

| GADM 单元 | GID_2 | 面积 | 对照 |
|---|---|---|---|
| Baltimore（马里兰州） | `USA.21.3_1` | 1,794 km² | 县 1,549 + 市 210 ≈ 1,759 |
| SaintLouis（密苏里州） | `USA.26.95_1` | 1,516 km² | 县 1,315 + 市 160 ≈ 1,475 |

两市质心均落在多边形内部，不是空洞。准确说法是面积没少、但分不开，按县汇总时这两个市会静默并进同名县。都市圈并集里的孔洞是简化产生的零面积缝隙，不是真实空洞。

### 英国层

- L1 英格兰的 `NAME_1` 在 GADM 为 NA，已由 `NAME_FIX` 补为 England；另 1 条属性全空，按无 GID 剔除，L2 剩 4 条。
- ADM2 共 183 条，82 条 `NAME_2` 为 NA。其中 3 条名称与类型同时为空（Greater London `GBR.1.36_1`、Buckinghamshire `GBR.1.13_1`、Lancashire `GBR.1.48_1`），按清洗规则剔除，L3 剩 180 条。
- 这 3 条正是伦敦、白金汉郡、兰开夏的父级，导致 49 条 L4 在 L3 中找不到父级（伦敦 32、白金汉郡 4、兰开夏 12，另 1 条父级为字符串 NA）。L3 视图在这三处为空。
- 其余 79 条 L3 无名字，界面显示 HASC 码（如 `GB.TM`）。
- L3 语义混杂，26 个 AdministrativeCounty 下设 district，与 64 个 UnitaryAuthority 并列。406 条 L4 里 284 条是真 district，72 条是单一制市镇在两层各画一遍的复本，49 条父级缺失。
- 上下层年份不一致：L3 已含 2019 年合并的 BCP，L4 仍是 Bournemouth 与 Poole；L4 还保留 2020 年撤销的 Chiltern、Wycombe、Aylesbury Vale、South Bucks。

结论是 L4 可以当 district/borough 层用，但父级要补；L3 不宜作郡级聚合，要用需换 ONS 或 Ordnance Survey 官方边界。

### 其他国家

用 `scripts/audit_admin_layers.py` 把 31 国逐层扫了一遍，比较原始与入库要素数、名称缺失、父级断裂、上下层复本。复本判据是父级只有一个子级且面积比在 1% 以内。

| 国家 | 层 | 现象 | 数量 | 影响 |
|---|---|---|---:|---|
| 俄罗斯 | L4 | 名称与类型全空，2,435 条与 L3 同形（面积比 1.0） | 2,435 / 2,562 | 清洗后剩 127，L4 视图大面积为空 |
| 阿联酋 | L4 | 同上，181 条与 L3 同形 | 181 / 530 | 清洗后剩 349 |
| 荷兰 | L2 | `NLD.14_1` 名称与类型全空，实为南荷兰省 | 1 / 14 | 清洗后剩 13，南荷兰省在 L2 视图为空 |
| 印度 | L4 | 名字为 `n.a.(编号)` | 147 / 2,347 | 保留，界面显示占位名 |
| 摩洛哥 | L4 | 名字为 NA | 242 / 399 | 保留，界面显示 NA |
| 泰国 | L4 | 名字为 NA | 197 / 5,926 | 保留，界面回退显示 GID |
| 西班牙 | L4 | n.a. 占位名 | 292 / 369 | 已换源 LAU 2024 |
| 秘鲁 / 伊朗 | L4 / L3 | 少量占位名 | 1 / 3 | 保留 |

另有 15 国只到 ADM2（美、日、巴西、阿根廷、澳大利亚、埃及、伊朗、墨西哥、马来西亚、尼日利亚、荷兰、新西兰、沙特、土耳其、台湾），L4 为空是层深不足，不是缺陷。

使用建议：英国用 L4 前先补父级；俄罗斯与阿联酋的 L4 等于没有，按 L3 聚合；荷兰按省聚合时补南荷兰省；印度、摩洛哥、泰国的 L4 空名需按官方名录补。

## 检索与标注消歧

地图依赖三份产物：`map_data/_search.js`（检索索引）、`map_data/{ISO3}.js`（各国几何与名称）、`interactive_map.html`（渲染）。本轮修掉两处缺陷：

1. 检索下拉只显示「国家 · 层级」，全库 4,038 组同名条目无法区分，如 `Merkez` ×73、`Washington` ×32。
2. 中文词典按名称建键、不分层级，L3/L4 有 176 条中文名被套上省级译名，最典型的是 31 个 Washington 县显示成「华盛顿州」。

修法有两条。检索条目新增上级字段 `p`，取自 GADM 行自带的 `GID_{level-2}` 与父级本地名，取不到时按「精确 GID、去版本后缀、子行祖先名」三级兜底；副标题改为「国家 · 上级 · 层级」。中文译名同时满足「该名确实是本国省名」与「译名带省级后缀」才清空，只作用于词典路径，中国走 `NL_NAME`，不受影响。

| 项 | 改前 | 改后 |
|---|---|---|
| L3/L4 条目带上级标签 | 0 | 57,886 / 57,895 = 99.98% |
| L3/L4 中文名带省级后缀 | 176 | 79（77 条中国 `NL_NAME`、2 条韩国清州与全州，本就正确） |
| 下拉能否区分同名 | 否 | 是 |

`scripts/build_interactive_map.py` 是唯一真源，`interactive_map.html`、`index.html` 与脚本内模板字节一致。重跑构建后各国 `map_data/{ISO3}.js` 字节不变，只有 `_search.js` 与两份 HTML 变化。

```bash
cd GADM
python scripts/build_interactive_map.py
cp interactive_map.html index.html
```
