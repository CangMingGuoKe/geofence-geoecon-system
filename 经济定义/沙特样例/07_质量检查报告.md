## 中东表的两种特殊结构

中东表是 8 列，但表头只定义 6 列（城市名 / 国家 / OE 城市代码 / 地理级别 / 本地层级 / 本地名称），**没有「本地代码」列**。所以本表所有国家都只能按**名称**匹配，没有代码桥可用。

整张表 29 个城市、26 个可拼、31 个成员条目。其中只有 3 个城市是多单元聚合：贝鲁特 2 个、Dammam 3 个、迪拜-沙迦-阿治曼 3 个；其余 23 个可拼城市都是一城一单元。以色列的 3 个城市（海法、耶路撒冷、特拉维夫）**一个成员单元都没有**，拼不了。

## 三层匹配：精确、剥冠词、别名

GADM 沙特的地名与 OE 差异很大，且普遍带阿拉伯语冠词前缀（Al / Ad / Ar / Ash / As / Az / At），所以匹配分四层：精确、剥冠词、手工别名、模糊（0.8）。别名只收有确证的对应关系：

| OE 写法 | GADM 写法 | 差异性质 |
|---|---|---|
| Riyadh | Riyadh | 无差异（精确命中） |
| Qatif | AlQatif | 剥掉冠词 Al 即命中 |
| Khobar | AlKhubar | 冠词 Al 加 o/u 拼写差异 |
| Jeddah | Jiddah | e/i 与 dd/d 的罗马化差异 |
| Mecca | MakkahAlMukarramah | **无共同前缀**，只能靠别名 |
| Medina | AlMadinah | **无共同前缀**，只能靠别名 |

**别名表只能手工建，因为 GADM 沙特没有任何别名字段可用**：L3 的 `VARNAME_2` 与 `NL_NAME_2` 整列为 `NA`，`CC_2` 与 `HASC_2` 也整列为空（0 / 147）。

**匹配是确定的**：归一化后同名键 0 组，剥冠词后同名键也 0 组（用两个独立计数器分别核过），因此不需要像巴西那样先定区再匹配，可以直接全局匹配。

## 一处缺口：Dammam

`Dammam` 圈由 3 个省聚合而成（Dammam、Khobar、Qatif），其中 **Dammam 省在 GADM 里没有对应单元**：

- 对全部 147 个 `Muhafazah`，在 `NAME_2`、`VARNAME_2`、`NL_NAME_2`、`NAME_1`、`NL_NAME_1` 五个字段里搜 `damm`、`damam`、`damman` 与阿拉伯语 `دمام`，**命中 0**。
- 东区（Ash-Sharqīyah）的 11 个省是 Abqaiq、AlAhsa、AlJubayl、AlKhafji、AlKhubar、AlNuayriyah、AlQatif、AlUdayd、HafarAlBatin、QaryahAlUlya、RasTannurah，Dammam 不在其中。
- 东区的别名字段与本地名字段整列为 `NA`，无法从别名字段救回。

**这条缺口的影响要说清楚**：交付的 Dammam 圈由 Khobar（197.9 km²）与 Qatif（639.7 km²）拼成，合计 837.6 km²，**不含达曼市本身的辖区**。也就是说这个圈的边界缺的恰是它的核心市。这是 GADM 的覆盖缺口，不是匹配方法的问题。用这个圈做研究时须知道它代表的是「达曼都市圈里除达曼市以外的部分」。

参照量级：东区 11 个省合计 521,903 km²，被 AlAhsa（241,179）与 AlUdayd（170,908）两个巨型内陆省主导，沿海诸省都很小（AlQatif 639.7、RasTannurah 243.1、AlKhubar 197.9）。

## 面积警示：GADM 沙特的几何覆盖偏小

**GADM 沙特几何合计比外部公开的国土面积参考值（非本项目数据，库内未留源）少 10.55%**，这不是投影或处理问题：

| 算法 | L2（13 区） | L3（147 省） |
|---|---|---|
| 测地面积（与投影无关） | 1,922,848 km² | 1,922,800 km² |
| 等积投影 EPSG:6933 | 1,923,049 km² | 1,923,037 km² |
| 沙特本地 Albers 等积投影 | 1,922,792 km² | 1,922,737 km² |

三种独立算法相差 0.02% 以内，且 L2 与 L3 互相吻合，说明投影选得对、层级内部一致；**官方参考值为 2,149,690 km²，GADM 沙特少了约 22.7 万 km²**。作为对照，同级的巴西 GADM 几何与官方只差 0.08%。使用时须知道 GADM 沙特的边界覆盖不完整（沙特的南、东边界本就有未定段）。

## 与前三例的差异：沙特特有的三处处理

1. **没有代码可对，也没有别名字段可用。** 美国有县 FIPS、日本有 JIS、巴西源表至少还有成员名可循；沙特所在的 Middle East 表连「本地代码」列都没有，GADM 沙特的别名字段又整列为空，所以别名表只能手工建（仅 4 条，逐条有确证）。
2. **成员的边界含义是「整个省」。** 沙特的「市」在源表里定义为 Governorate，对应 GADM L3 的 147 个 `Muhafazah`。4 个城市是一城一省，因此 `Riyadh` 圈 8,517 km²、`Medina` 圈 22,938 km² 都是**整个省**的范围，而不是城区。这与欧洲的 City Proper 同类，放进图层时须与美日那种「多成员聚合的都市圈」区分开。
3. **`Jeddah` 圈由 120 块构成**（本土加岛屿），是四个样例里碎块最多的一个；地图端已按 0.005 度简化。
